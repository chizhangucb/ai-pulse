# Reporting security issues

If you find a permission bypass, a leaked secret, an injection or another problem that may affect the security of a deployment, contact the maintainers through [GitHub private vulnerability reporting](https://github.com/KKKKhazix/AIHOT/security/advisories/new).

Please include:

- the affected commit, the deployment method and the environment details that matter;
- the fewest steps to reproduce the problem in an environment you are authorized to test;
- the possible impact, and logs or screenshots with sensitive information removed.

Do not disclose exploitable details early in a public Issue, discussion or PR, and do not upload real keys, passwords, cookies, user data or a full database. For ordinary usage questions and bugs that are not security issues, use the [discussions](https://github.com/KKKKhazix/AIHOT/discussions/categories/q-a) or [Issues](https://github.com/KKKKhazix/AIHOT/issues/new/choose).

Security issues are verified and fixed on the latest `main` of the public repository first; there is no separately maintained long-term support branch. The maintainers confirm the scope, prepare a fix and publish a note when appropriate; no fixed response time is promised for now.
